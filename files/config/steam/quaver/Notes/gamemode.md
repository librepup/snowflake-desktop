# GameMode Commands
## Toggle GameMode
In case Quaver or any other game ever starts lagging and stuttering incredibly, or runs at close to 0FPS, you can run these commands in order:
1. gamemoded --request=<PID>
Then wait a few seconds and try interacting with the game. After everything is back to normal, run:
2. gamemoded --request=<PID>
... again.
